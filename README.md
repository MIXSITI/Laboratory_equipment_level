# Система бронирования лабораторного оборудования

Консольное приложение для учета лабораторного оборудования
и управления его бронированием.

## Возможности
- просмотр и поиск оборудования;
- проверка технической готовности прибора;
- проверка доступности на дату;
- добавление бронирований с контролем допуска;
- отмена бронирований;
- просмотр пользователей и статистики.

## Структура проекта
- main.py – точка запуска;
- equipment.py – работа с оборудованием;
- users.py – работа с пользователями;
- bookings.py – работа с бронированиями;
- storage.py – сохранение и загрузка данных;
- utils.py – вспомогательные функции;
- data/ – JSON-файлы данных;
- tests/ – автоматизированные тесты.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
pip install -r requirements.txt

## Запуск программы
python main.py

## Запуск тестов
pytest

## Проверка качества кода
flake8
