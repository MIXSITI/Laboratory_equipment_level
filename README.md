# Система бронирования лабораторного оборудования

Консольное приложение на языке Python для автоматизации учета лабораторного
оборудования, контроля квалификационного допуска пользователей и управления
процессом бронирования приборов учебно-научной лаборатории.

В рамках **Практической работы № 3 (ПР3)** осуществлен полноценный переход от
функциональной модели (коллекций словарей ПР2) к объектно-ориентированной модели:
основные сущности предметной области представлены классами, поведение инкапсулировано
в методах, реализовано объектное связывание (композиция), наследование и полиморфизм.

## Назначение

Приложение предназначено для автоматизации учета, проверки готовности и
бронирования лабораторного оборудования. Система исключает накладки в
расписании, контролирует уровень допуска исследователей и факт прохождения
инструктажа по технике безопасности, а также рассчитывает стоимость аренды
с учетом льготных скидок для студентов.

## Целевая аудитория

- Студенты и аспиранты, выполняющие лабораторные работы и научные исследования.
- Преподаватели и научные руководители, планирующие практические занятия.
- Заведующие лабораториями и лаборанты (администраторы), отвечающие за
  исправность приборов, проведение инструктажей и допуск пользователей.

## Предметная область

Предметная область охватывает процесс регламентированного доступа к
специализированному оборудованию лаборатории (спектрофотометры, электронные
микроскопы, осциллографы, 3D-принтеры).
Ключевые аспекты:
- учет технического состояния приборов (исправность, нахождение на техобслуживании);
- контроль прав доступа пользователя (наличие инструктажа по ТБ, квалификационный
  уровень допуска от 1 до 3);
- расчет стоимости использования прибора (базовая почасовая ставка со скидкой
  50% для студентов);
- создание, учет и отмена бронирований на определенные даты.
- одно помещение/прибор не может иметь двух активных бронирований на одну и ту же дату;
- отмененное бронирование сохраняется в базе для аудита, но освобождает дату для новых заявок.

## Основные сущности и объектная модель (ООП)

### 1. `Equipment` — лабораторное оборудование (`models/equipment.py`)
Описывает физический прибор или исследовательский стенд лаборатории.
- **Основные атрибуты:**
  - `id: int` — уникальный идентификатор прибора;
  - `name: str` — наименование оборудования;
  - `inventory_number: str` — инвентарный номер (например, `EQ-301`);
  - `operational: bool` — флаг исправности прибора;
  - `under_maintenance: bool` — флаг нахождения на техническом обслуживании;
  - `required_level: int` — требуемый уровень квалификационного допуска (1–3);
  - `hourly_rate: float` — базовая стоимость аренды (руб/час).
- **Методы и свойства:**
  - `@property is_ready -> bool` — свойство готовности оборудования к работе;
  - `check_readiness() -> str` — текстовый статус технического состояния;
  - `is_suitable_for_level(user_level: int) -> bool` — проверка соответствия уровня допуска;
  - `@staticmethod validate_rate(rate: float) -> bool` — валидация корректности почасовой ставки;
  - `@staticmethod validate_level(level: int) -> bool` — валидация уровня допуска;
  - `@classmethod from_data(data: dict) -> Equipment` — фабричный метод создания объекта из JSON;
  - `to_dict() -> dict` — сериализация объекта в словарь для JSON;
  - `__str__() -> str` — удобное строковое представление оборудования.

### 2. `User` — пользователь лаборатории (`models/users.py`)
Базовый класс субъекта, работающего с приборами.
- **Основные атрибуты:**
  - `id: int` — уникальный идентификатор пользователя;
  - `name: str` — ФИО пользователя;
  - `role: str` — статус пользователя («студент» или «сотрудник»);
  - `access_level: int` — квалификационный уровень допуска (1–3);
  - `briefing_passed: bool` — отметка о прохождении инструктажа по технике безопасности;
  - `email: str` — контактный адрес электронной почты.
- **Методы и наследование:**
  - `has_access(required_level: int) -> bool` — проверка допуска к прибору с учетом ТБ;
  - `is_student() -> bool` — проверка роли студента;
  - `get_discount() -> float` — полиморфный метод расчета скидки на бронирование;
  - `@staticmethod validate_level(level: int) -> bool` — валидация уровня допуска;
  - `@classmethod from_data(data: dict) -> User` — создание соответствующего подкласса (`Student` / `Staff`);
  - `to_dict() -> dict` — сериализация профиля пользователя;
  - `__str__() -> str` — строковое представление пользователя.

#### Иерархия наследования и полиморфизм:
- **`Student(User)`** — подкласс студента. Переопределяет `get_discount() -> 0.5` (скидка 50%).
- **`Staff(User)`** — подкласс сотрудника. Переопределяет `get_discount() -> 0.0` (полная ставка).

### 3. `Booking` — бронирование оборудования (`models/bookings.py`)
Описывает резервирование оборудования конкретным пользователем на определенную дату.
Реализует **композицию объектов**, сохраняя ссылки на объекты `Equipment` и `User`.
- **Основные атрибуты:**
  - `id: int` — номер заявки;
  - `equipment: Equipment` — ссылка на объект оборудования (псевдоним `room` для совместимости);
  - `booking_date: date` — календарная дата бронирования;
  - `user: User` — ссылка на объект пользователя;
  - `duration_hours: float` — длительность сеанса в часах;
  - `cost: float` — рассчитанная стоимость бронирования;
  - `is_cancelled: bool` — статус отмены заявки (по умолчанию `False`).
- **Методы и свойства:**
  - `cancel() -> None` — отмена бронирования (изменяет состояние объекта, не удаляя его);
  - `@property status -> str` — статус («Подтверждено» / «Отменено»);
  - `@property room -> Equipment` — псевдоним прибора для совместимости;
  - `to_dict() -> dict` — сериализация заявки в формат с сохранением `equipment_id` и `user_id`;
  - `__str__() -> str` — строковое представление бронирования.

## Основные операции приложения

### 1. Операции с оборудованием (`models/equipment.py`)
- `add_equipment()` — создание объекта `Equipment` и добавление в коллекцию;
- `find_equipment()` — поиск приборов по подстроке названия и инвентарному номеру;
- `filter_equipment_by_level()` — генератор отбора доступных приборов через `yield`;
- `sort_equipment()` — сортировка приборов по почасовой ставке через `lambda`-функцию;
- `get_equipment_by_id()` — поиск объекта оборудования по первичному ключу ID;
- `show_equipment()` — вывод таблицы оборудования с текущим техническим статусом.

### 2. Операции с пользователями (`models/users.py`)
- `add_user()` — создание объекта `Student`, `Staff` или `User` и добавление в коллекцию;
- `find_user()` — поиск пользователей по ФИО и адресу электронной почты;
- `check_user_access()` — проверка прав доступа пользователя к оборудованию;
- `get_user_by_id()` — поиск объекта пользователя по первичному ключу ID;
- `show_users()` — форматированный вывод списка пользователей и отметок по ТБ.

### 3. Операции с бронированиями (`models/bookings.py`)
- `create_booking()` — создание объекта `Booking` со связями к `Equipment` и `User`, расчет стоимости;
- `is_equipment_available()` — проверка доступности прибора (отмененные брони не блокируют дату);
- `cancel_booking()` — поиск заявки и вызов метода `booking.cancel()`;
- `calculate_booking_cost()` — расчет стоимости аренды с учетом льгот;
- `get_booking_statistics()` — агрегация статистики по активным заявкам и оборудованию;
- `show_bookings()` — вывод реестра заявок со статусами активности.

## Хранение данных (JSON)

Данные приложения сохраняются в текстовых файлах формата JSON в каталоге `data/`.
При запуске функции модуля `storage.py` загружают структуры JSON и создают объекты
соответствующих классов, а при выходе — сериализуют объекты обратно в JSON.

### `data/equipment.json`
```json
[
  {
    "id": 1,
    "name": "Спектрофотометр UV-1800",
    "inventory_number": "EQ-301",
    "operational": true,
    "under_maintenance": false,
    "required_level": 2,
    "hourly_rate": 1200.0
  }
]
```

### `data/users.json`
```json
[
  {
    "id": 1,
    "name": "Иванов Алексей Сергеевич",
    "role": "студент",
    "access_level": 2,
    "briefing_passed": true
  }
]
```

### `data/bookings.json`
В файле сохраняются внешние ключи `equipment_id` и `user_id`, а также флаг `is_cancelled`:
```json
[
  {
    "id": 1,
    "equipment_id": 1,
    "user_id": 1,
    "booking_date": "2026-07-15",
    "duration_hours": 3.0,
    "cost": 1800.0,
    "is_cancelled": false
  }
]
```
