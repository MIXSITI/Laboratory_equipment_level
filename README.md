# Система бронирования лабораторного оборудования.

Консольное приложение для автоматизации учета лабораторного оборудования,
контроля квалификационного допуска пользователей и управления бронированием.

## Назначение

Приложение предназначено для автоматизации учета, проверки доступности и
бронирования лабораторного и исследовательского оборудования учебно-научной
лаборатории. Система исключает накладки в расписании, контролирует квалификацию
пользователей и факт прохождения инструктажа по технике безопасности, а также
рассчитывает стоимость аренды оборудования с учетом льгот для студентов.

## Целевая аудитория

- Студенты и аспиранты, выполняющие лабораторные работы и научные исследования.
- Преподаватели и научные руководители, планирующие практические занятия.
- Заведующие лабораториями и лаборанты (администраторы), отвечающие за
  исправность приборов, проведение инструктажей и допуск пользователей.

## Предметная область

Предметная область охватывает процесс предоставления регламентированного доступа
к специализированному оборудованию учебно-научной лаборатории (спектрометры,
электронные микроскопы, осциллографы, 3D-принтеры). Ключевыми аспектами являются:
- учет технического состояния приборов (исправность, нахождение на ТО);
- контроль прав доступа пользователя (наличие инструктажа по ТБ, требуемый
  уровень допуска от 1 до 3);
- расчет стоимости использования прибора (базовая почасовая ставка со скидкой
  50% для студентов);
- регистрация и отмена бронирований на определенные даты.

## Основные сущности

- **Оборудование** — физический прибор или стенд (идентификатор, наименование,
  инвентарный номер, исправность, нахождение на ТО, требуемый уровень допуска,
  почасовая ставка аренды).
- **Пользователь** — субъект, работающий с оборудованием (идентификатор, ФИО,
  роль: студент или сотрудник, квалификационный уровень допуска, отметка о
  прохождении инструктажа по ТБ).
- **Бронирование** — факт резервирования прибора на определенную дату
  (идентификатор заявки, прибор, пользователь, дата, длительность в часах,
  итоговая стоимость).

## Возможности программы (ПР1 и ПР2)

- Просмотр списка оборудования в виде форматированной таблицы с сортировкой
  по почасовой ставке (`lambda`-функция);
- Поиск оборудования по подстроке названия и инвентарному номеру;
- Проверка технической готовности оборудования (исправность и отсутствие ТО);
- Проверка доступности оборудования на выбранную календарную дату;
- Создание бронирования с многоуровневым контролем допуска (проверка
  исправности прибора, уровня допуска пользователя, прохождения инструктажа
  по ТБ и отсутствия повторного бронирования на эту же дату);
- Расчет стоимости аренды со скидкой 50% для студентов;
- Отмена бронирования по номеру заявки;
- Просмотр списка бронирований с отображением прибора, пользователя и стоимости;
- Просмотр списка зарегистрированных пользователей лаборатории;
- Сводная статистика по бронированиям (количество заявок, число задействованных
  приборов, общая сумма, отбор оборудования 1-го уровня через генератор `yield`);
- Добавление нового оборудования и пользователей с мгновенным сохранением в JSON;
- Безопасный ввод данных с обработкой исключений (`ValueError`);
- Персистентное хранение данных в JSON-файлах через контекстный менеджер `with`;
- Интроспекция объектов Python (`type()`, `id()`, `dir()`, `callable()`,
  `getattr()`, `isinstance()`).

## Структура проекта

- `main.py` – точка запуска приложения, организация цикла консольного меню;
- `equipment.py` – функции работы с оборудованием (добавление, поиск, проверка
  готовности, сортировка через `lambda`, генератор фильтрации по уровню допуска);
- `users.py` – функции работы с пользователями (добавление, поиск, проверка
  прав доступа и инструктажа по ТБ);
- `bookings.py` – функции управления бронированиями (проверка доступности на дату,
  создание, отмена, расчет стоимости сеанса, сбор статистики);
- `storage.py` – сохранение и загрузка данных в формате JSON с использованием
  контекстных менеджеров `with` и обработкой исключений;
- `utils.py` – вспомогательные функции валидации пользовательского ввода
  и функция интроспекции объектов;
- `data/` – каталог с файлами данных в формате JSON:
  - `data/equipment.json` – данные об оборудовании;
  - `data/users.json` – данные о пользователях;
  - `data/bookings.json` – данные о совершенных бронированиях;
- `tests/` – автоматизированные тесты на платформе `pytest`:
  - `tests/test_equipment.py` – тесты оборудования, пользователей, генераторов
    и интроспекции;
  - `tests/test_bookings.py` – тесты логики бронирования, расчета стоимости,
    статистики и файлового хранилища.
- `requirements.txt` – зависимости проекта для тестирования и контроля качества;
- `.gitignore` – правила исключения временных файлов и каталогов.

## Требования к окружению

- Python 3.10+;
- pytest >= 8.0;
- flake8 >= 7.0.

Установка зависимостей:
```bash
pip install -r requirements.txt
```
