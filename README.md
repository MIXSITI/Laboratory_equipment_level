# Система бронирования лабораторного оборудования

## Назначение
Приложение для учета, проверки технической готовности и бронирования оборудования
учебно-научной лаборатории.

Консольная версия приложения (**ПР3**) дополнена веб-интерфейсом на фреймворке **Django** (**ПР5**).

Приложение позволяет:
* просматривать каталог лабораторного оборудования в веб-браузере;
* просматривать подробную карточку конкретного прибора (инвентарный номер, ставку, уровень допуска, исправность);
* проверять доступность оборудования на текущую календарную дату;
* просматривать список активных и отмененных заявок на бронирование;
* просматривать карточку отдельного бронирования с данными о пользователе, длительности и стоимости;
* находить приборы по наименованию и инвентарному номеру (консольная версия);
* фильтровать приборы по требуемому уровню допуска (консольная версия);
* создавать новые бронирования со скидкой для студентов (консольная версия);
* отменять бронирования с освобождением даты (консольная версия);
* сохранять и загружать данные в формате JSON между сессиями работы.

## Используемые технологии
* **Python 3.10+**;
* **Django 5.2** — веб-фреймворк;
* **HTML5** — разметка веб-страниц;
* **CSS3** и **Bootstrap 5.3** (через CDN) — оформление и адаптивная верстка интерфейса;
* **pytest** — модульное и интеграционное тестирование;
* **flake8** — проверка качества кода на соответствие стандарту PEP 8.

## Целевая аудитория
* Студенты и аспиранты, выполняющие научно-исследовательские и лабораторные работы;
* Преподаватели и научные руководители, планирующие практические занятия;
* Лаборанты и администраторы лаборатории, контролирующие состояние приборов и допуск пользователей.

## Предметная область
Основными объектами предметной области являются:
* **Оборудование (`Equipment`)**;
* **Пользователь (`User`)**;
* **Бронирование (`Booking`)**.

Сущность **Период (`Period`)** (календарная дата и длительность в часах) **отдельно в самостоятельную сущность/модель не выносится**, а инкапсулирована внутри сущности **Бронирование**.

Правила предметной области:
* Пользователь может создавать бронирования оборудования на определенные даты;
* Один прибор не может иметь двух активных бронирований на одну и ту же дату;
* Отмененное бронирование сохраняется в истории, но не блокирует прибор на эту дату;
* Студенты имеют льготную скидку 50% на почасовую ставку аренды оборудования.

## Основные сущности

### 1. `Equipment` — лабораторное оборудование (`models/equipment.py`)
Описывает прибор или рабочий стенд лаборатории.
* **Основные атрибуты:**
  * `id` — уникальный идентификатор прибора;
  * `name` — наименование оборудования;
  * `inventory_number` — инвентарный номер (например, `EQ-301`);
  * `operational` — флаг исправности прибора;
  * `under_maintenance` — отметка о проведении технического обслуживания;
  * `required_level` — требуемый уровень допуска (1–3);
  * `hourly_rate` — базовая стоимость аренды в руб/час;
  * `capacity` — вместимость рабочего места прибора.
* **Основные методы:**
  * `check_readiness()` — проверка готовности оборудования к эксплуатации;
  * `is_suitable_for_level()` — проверка соответствия допуска исследователя;
  * `__str__()` — строковое представление прибора.

### 2. `User` — пользователь системы (`models/users.py`)
Описывает пользователя лаборатории (базовый класс с подклассами `Student` и `Staff`).
* **Основные атрибуты:**
  * `id` — уникальный идентификатор пользователя;
  * `name` — ФИО пользователя;
  * `role` — роль («студент» или «сотрудник»);
  * `access_level` — уровень квалификационного допуска (1–3);
  * `briefing_passed` — отметка о прохождении обязательного инструктажа по ТБ;
  * `email` — контактный e-mail.
* **Основные методы:**
  * `has_access()` — проверка допуска к прибору с учетом инструктажа;
  * `get_discount()` — полиморфный расчет скидки на аренду (50% для студентов, 0% для сотрудников);
  * `__str__()` — строковое представление пользователя.

### 3. `Booking` — бронирование (`models/bookings.py`)
Описывает факт резервирования прибора исследователем.
* **Основные атрибуты:**
  * `id` — номер заявки;
  * `equipment` — ссылка на объект оборудования (`Equipment`);
  * `period` — инкапсулированный объект периода (`Period`: дата `booking_date` и длительность `duration_hours`);
  * `user` — ссылка на объект пользователя (`User`);
  * `cost` — итоговая расчетная стоимость;
  * `is_cancelled` — признак отмены заявки.
* **Основные методы:**
  * `cancel()` — отмена заявки без удаления объекта;
  * `@property status` — текстовый статус («Подтверждено» / «Отменено»);
  * `__str__()` — строковое представление заявки.

## Страницы веб-интерфейса
* `/` — главная страница: описание сервиса, общая навигация и быстрые кнопки перехода (view-функция `index()`);
* `/equipment/` — каталог лабораторного оборудования: объекты `Equipment` из `data/equipment.json` (view-функция `equipment_list()`);
* `/equipment/<int:equipment_id>/` — карточка прибора: техническое состояние, параметры допуска, ставка и доступность на текущую дату (view-функция `equipment_detail()`);
* `/bookings/` — реестр бронирований: объекты `Booking` из `data/bookings.json` со статусами (view-функция `bookings()`);
* `/bookings/<int:booking_id>/` — карточка бронирования: сведения о приборе, пользователе, длительности и стоимости (view-функция `booking_detail()`).

Для обеспечения полной обратной совместимости с тестовыми сценариями методических указаний также поддерживаются псевдонимы маршрутов:
* `/rooms/` — список объектов (view-функция `rooms()`);
* `/rooms/<int:room_id>/` — детальная информация (view-функция `room_detail()`).

Если оборудование или бронирование с указанным идентификатором не найдено, возвращается страница ошибки с кодом статуса **404 Not Found**.

## Основные операции

### Используется в веб-интерфейсе (ПР5)
* просмотр каталога лабораторного оборудования;
* просмотр карточки прибора и его технической готовности;
* просмотр реестра бронирований;
* просмотр детальной информации по заявке;
* проверка доступности оборудования на текущую дату через функцию `is_equipment_available()`.

### Отложено до следующих работ
Эти операции работают в консольной версии (ПР3) и будут перенесены в веб при внедрении форм и POST-запросов:
* добавление нового оборудования в каталог (`add_equipment()`);
* поиск приборов по наименованию и инвентарному номеру (`find_equipment()`);
* фильтрация приборов по уровню допуска (`filter_equipment_by_level()`);
* создание бронирования с расчетом скидки (`create_booking()`);
* отмена бронирования (`cancel_booking()`);
* регистрация и аутентификация пользователей.

## Хранение данных
Данные хранятся в JSON-файлах в каталоге `data/`:
* `data/equipment.json` — реестр приборов;
* `data/users.json` — список пользователей;
* `data/bookings.json` — история и активные заявки бронирования.

Связывание бронирований с оборудованием и пользователями осуществляется по внешним ключам `equipment_id` и `user_id`. Модуль `storage.py` восстанавливает полноценные объектные связи при загрузке.

## Назначение модулей

### `homepage/views.py`
Содержит общую функцию `page(title, content)`, формирующую корректный HTML5-документ с метатегами, адаптивным контейнером и стилями Bootstrap 5.3 через CDN, а также view-функцию `index(request)`.

### `equipment/views.py`
Обрабатывает каталог приборов `equipment_list(request)` и карточку прибора `equipment_detail(request, equipment_id)` с проверкой доступности на текущую дату через `is_equipment_available()`.

### `bookings/views.py`
Обрабатывает список бронирований `bookings(request)` и карточку бронирования `booking_detail(request, booking_id)` с поиском по идентификатору через `find_booking_by_id()`.

### `models/bookings.py`
Содержит класс `Booking`, сущность `Period`, функцию поиска `find_booking_by_id()` и функцию проверки доступности `is_equipment_available()`.
